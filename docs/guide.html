คู่มือการใช้งาน Check EDI Various Forms (HAHM)

เวปนี้ใช้เทียบ MANIFEST ของสายเรือกับ ENTER ชุดรวมของงาน HAHM ซึ่งเป็น PDF ไฟล์เดียวที่รวมเอกสารหลาย Forwarder ได้ผลเป็นรายงาน Excel ใส่สี ช่องไหนไม่ตรงจะเห็นทันทีก่อนยื่นใบขนสินค้าขาเข้า

MANIFEST (.xls/.xlsx)+ENTER ชุดรวม (.pdf)→EDI HAHM.xlsx

ไฟล์ประมวลผลในเบราว์เซอร์ของเครื่องคุณเท่านั้น ไม่มีการอัปโหลดไปที่ใด · ไม่ต้องติดตั้งโปรแกรม

ขั้นตอนการใช้งาน ฟอร์มที่อ่านได้ อ่านรายงาน กฎการเทียบ ใช้แบบออฟไลน์ ถ้าเจอปัญหา

ขั้นตอนการใช้งาน

  1. ใส่ไฟล์ ลากไฟล์ MANIFEST และ ENTER มาวางพร้อมกัน หรือคลิกกรอบเพื่อเลือกไฟล์
    ตั้งชื่อไฟล์อะไรก็ได้ เวปแยกให้เอง (.xls/.xlsx = MANIFEST, .pdf = ENTER) · ENTER หลายไฟล์ของเรือลำเดียวกันใส่พร้อมกันได้
  2. ตรวจ SHED NO. ค่าเริ่มต้น: B/L ที่ STATUS เป็น CFS/LCL = 0141 · ที่เหลือ (CY) = 0122 แก้ได้ตามงาน
    ถ้าไม่ต้องการตรวจ SHED ตาม STATUS ให้ลบทั้งสองช่อง
  3. กด “ตรวจสอบ” ใช้เวลาไม่กี่วินาที ด้านบนผลจะบอกว่า ENTER มีฟอร์มอะไรบ้างกี่หน้า และหน้าไหนเป็นภาพสแกน
  4. ดูผลในตาราง ค้นหา B/L / ชื่อผู้รับ / เลขตู้ ได้ · ติ๊ก “แสดงเฉพาะที่ไม่ตรง” เพื่อดูแค่แถวที่ต้องแก้
  5. กด “ดาวน์โหลด EDI.xlsx” ได้ไฟล์ EDI HAHM.xlsx หน้าตาเดียวกับตาราง

ฟอร์มใน ENTER ชุดรวมที่อ่านได้

เวปแยกชนิดของ ENTER ให้ทีละหน้า แล้วอ่านแต่ละหน้าด้วยวิธีของฟอร์มนั้น

ชนิดหน้าอ่านอะไรบ้าง
ARRIVAL NOTICE / สำเนา B/L ของ Heung-Aชื่อผู้รับ (ถ้าเป็น TO ORDER ใช้ชื่อ Notify), เลขตู้, จำนวน, G.W., MEAS., MARKS, DESC และข้อความที่ลูกค้าพิมพ์เพิ่ม เช่น STATUS ลากตู้ / CLASS 9 UN 3077
ATTACHED RIDERMARKS ในใบ RIDER แทนคำว่า “AS PER ATTACHED RIDER” ในหน้า B/L
ใบ MARK&NO.2 B/L ต่อหน้า: MARKS, จำนวน, ชนิดหีบห่อ, ผู้รับ, DESC, เลขตู้, G.W., MEAS.
ตาราง AMENDMENTCargoport, ASIA ATLANTIC, INITIAL, Handle ฯลฯ · STATUS หรือเลขตู้ที่เขียนไว้ครั้งเดียวใช้กับทุก B/L ในฉบับนั้น
จดหมายแก้ไขอ่านจากป้าย เช่น CNEE / CONTAINER NO. / Status / MARKS · MARKS/DESC ไม่ตรงจะขึ้นสีส้ม (ให้คนยืนยัน)
MAC-NELS · THE M CORP · DSVใช้ตัวอ่านเดียวกับเวปของเจ้านั้น
ภาพสแกนอ่านอัตโนมัติไม่ได้ — รายงานขึ้นสีส้ม “ตรวจด้วยตา” พร้อมเลขหน้า

อ่านรายงาน

หนึ่งแถวต่อหนึ่ง B/L ช่องซ้ายสุดสรุปว่าแถวนั้นต้องดูอะไร ค่าของ ENTER และ MANIFEST วางคู่กันทุกหัวข้อ ช่องหมายเหตุขึ้นต้นด้วย [ENTER หน้า n] บอกว่าค่ามาจากหน้าไหนของ PDF เปิดไปดูต้นฉบับได้ทันที

ขาว — ไม่ผิด
เขียว — ผ่าน ไม่พบจุดผิด
แดง ⚠ — ไม่ตรงกัน ต้องแก้หรือยืนยันก่อนยื่น
ส้ม — ต้องให้คนยืนยัน หรือ ENTER เป็นภาพสแกนต้องตรวจด้วยตา
เหลือง — ไม่มีเอกสาร ENTER ให้เทียบ

หัวข้อที่เทียบทุก B/L

  • CONSIGNEE และ TAX ID
  • CONTAINER NO. และ STATUS
  • จำนวนและชนิดหีบห่อ (PKG), G.W., MEAS.
  • MARKS และ DESCRIPTION
  • SHED NO., ประเทศปลายทาง, CARGO MOVEMENT

เตือนเสมอเมื่อพบ

  • DG (CLASS / UN)
  • REEFER TEMP
  • INTRANSIT / TRANSHIPMENT
  • MEAS. ใน MANIFEST เป็น 0.000 แต่ ENTER มีค่า
  • B/L ที่มีใน ENTER แต่ไม่มีใน MANIFEST (วิกฤต)

กฎการเทียบที่ควรรู้

  • STATUS: CY / CY-CY / FCL / ลากตู้ = CY · LCL / ขน = LCL · CFS / LCL-CFS / เปิดตู้ = LCL/CFS
  • SHED NO.: ใช้ STATUS ตามคำสั่งใน ENTER (ถ้า ENTER ไม่ระบุจึงใช้ของ MANIFEST) → CFS/LCL ต้องเป็นเลขช่องแรก ที่เหลือต้องเป็นเลขช่องที่สอง
  • ARRIVAL NOTICE / สำเนา B/L ของ Heung-A: ถ้า MARKS/DESC ใน MANIFEST เป็นส่วนหนึ่งของข้อความบน B/L ถือว่าตรง หมายเหตุจะบอกว่า ENTER มีข้อความอะไรเพิ่ม
  • ข้อความสีแดงที่ลูกค้าพิมพ์ทับ PDF = คำสั่งจริงของลูกค้า (STATUS, DG, REEFER, แก้ชื่อผู้รับ, เลขตู้)
  • B/L ที่มีหลายตู้ ต้องตรงกับ MANIFEST ครบทุกตู้
  • TRANSHIPMENT: CARGO MOVEMENT ต้องเป็น 3-TRANSHIPMENT
  • SHED / ประเทศปลายทาง / CARGO MOVEMENT / TAX ID ถ้าถูกต้องตามกฎจะแสดง -

ใช้แบบออฟไลน์ (Python)

  1. ติดตั้ง Python 3 จาก python.org (ติ๊ก “Add python.exe to PATH”)
  2. ดาวน์โหลดโปรแกรม หน้า GitHub repo กด Code → Download ZIP แล้วแตกไฟล์
  3. ใส่ไฟล์ MANIFEST และ ENTER ในโฟลเดอร์ input แล้วดับเบิลคลิก run-check-edi.bat
  4. ผลอยู่ใน output\EDI-HAHM.xlsx (รอบต่อไปเป็น -2, -3 … ไม่ทับไฟล์เดิม) โปรแกรมตรวจย้อนให้ด้วยว่าทุกค่าในรายงานมาจากไฟล์จริง

Check EDI Various Forms (HAHM) — User Guide

This page compares the carrier's MANIFEST with the HAHM ENTER bundle, a single PDF that combines documents from many forwarders. The result is a colour-coded Excel report, so every mismatch is visible before the import customs declaration is filed.

MANIFEST (.xls/.xlsx)+ENTER bundle (.pdf)→EDI HAHM.xlsx

Files are processed only in your browser; nothing is uploaded. No installation needed.

How to use Forms it reads Reading the report Comparison rules Offline use Troubleshooting

How to use

  1. Add the files. Drag the MANIFEST and ENTER files onto the box together, or click the box to choose them.
    Any file name works; the page sorts them itself (.xls/.xlsx = MANIFEST, .pdf = ENTER). Several ENTER files for the same vessel can be added at once.
  2. Check the SHED NO. boxes. Defaults: B/Ls with STATUS CFS/LCL = 0141, all others (CY) = 0122. Change them to suit the job.
    Clear both boxes to skip the SHED-by-status check.
  3. Click “ตรวจสอบ” (Check). It takes a few seconds. Above the table the page lists which forms the ENTER contains, how many pages each, and which pages are scans.
  4. Review the table. Search by B/L, consignee or container; tick “แสดงเฉพาะที่ไม่ตรง” to show only rows that need attention.
  5. Click “ดาวน์โหลด EDI.xlsx”. You get EDI HAHM.xlsx, laid out like the table.

Forms it reads inside the ENTER bundle

The page identifies each ENTER page and reads it the way that form is laid out.

Page typeWhat is read
Heung-A ARRIVAL NOTICE / B/L copyConsignee (the Notify name when it says TO ORDER), containers, package count, G.W., MEAS., MARKS, DESC, and anything the customer typed on, such as STATUS ลากตู้ or CLASS 9 UN 3077
ATTACHED RIDERThe rider's marks replace “AS PER ATTACHED RIDER” on the B/L page
MARK&NO. sheetTwo B/Ls per page: marks, package count and type, consignee, description, container, G.W., MEAS.
AMENDMENT tableCargoport, ASIA ATLANTIC, INITIAL, Handle and similar. A STATUS or container stated once applies to every B/L of that document
Amendment letterRead from its labels (CNEE / CONTAINER NO. / Status / MARKS …). MARKS/DESC mismatches are orange (needs a person to confirm)
MAC-NELS · THE M CORP · DSVRead with the same reader as that forwarder's own page
Scanned pageCannot be read automatically; the report shows it in orange as “ตรวจด้วยตา” (check by eye) with the page number

Reading the report

One row per B/L. The leftmost column summarises what needs attention; ENTER and MANIFEST values sit side by side for every item. The notes column starts with [ENTER หน้า n], the PDF page the values came from, so you can open the source straight away.

White — no error
Green — passed
Red ⚠ — mismatch; fix or confirm before filing
Orange — needs a person to confirm, or the ENTER page is a scan to check by eye
Yellow — no ENTER document to compare

Compared for every B/L

  • CONSIGNEE and TAX ID
  • CONTAINER NO. and STATUS
  • Package count and type, G.W., MEAS.
  • MARKS and DESCRIPTION
  • SHED NO., destination country, CARGO MOVEMENT

Always flagged when found

  • DG (CLASS / UN)
  • REEFER TEMP
  • INTRANSIT / TRANSHIPMENT
  • MEAS. 0.000 in MANIFEST while ENTER has a value
  • B/L in ENTER but missing from MANIFEST (critical)

Comparison rules worth knowing

  • STATUS: CY / CY-CY / FCL / ลากตู้ = CY · LCL / ขน = LCL · CFS / LCL-CFS / เปิดตู้ = LCL/CFS
  • SHED NO.: uses the customer's STATUS in ENTER (MANIFEST's when ENTER gives none): CFS/LCL must match the first box, everything else the second
  • Heung-A ARRIVAL NOTICE / B/L copy: when the MANIFEST MARKS/DESC is part of the B/L text it counts as a match; the note lists the extra B/L text
  • Red text typed on the PDF is the customer's real instruction (STATUS, DG, REEFER, consignee correction, containers)
  • A B/L with several containers must match every container in the MANIFEST
  • TRANSHIPMENT: CARGO MOVEMENT must be 3-TRANSHIPMENT
  • SHED / destination / CARGO MOVEMENT / TAX ID show - when correct

Offline use (Python)

  1. Install Python 3 from python.org (tick “Add python.exe to PATH”).
  2. Download the program: on the GitHub repo click Code → Download ZIP and extract it.
  3. Put the files (MANIFEST and ENTER) in the input folder and double-click run-check-edi.bat.
  4. The result is output\EDI-HAHM.xlsx (next runs: -2, -3 … existing reports are never overwritten). It also traces every report value back to the original files.

Troubleshooting

SymptomWhat to do
“ตรวจสอบ” cannot be clickedBoth a MANIFEST and an ENTER file are needed
A B/L is yellow / orange “ตรวจด้วยตา”The B/L is on a scanned page or not in the ENTER — open the PDF page named in the note and check it yourself
Many ENTER cells are emptyIt may be a new form that is not supported yet; send the file to Rattana so it can be added
The page still looks oldPress Ctrl + F5 to reload
Can't find the downloaded fileLook in Downloads for EDI HAHM.xlsx
This report is a checking aid only. Before filing, a person must review every red or orange cell and every scanned page.
